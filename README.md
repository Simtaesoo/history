# 중·고 역사 수업실

2022 개정 교육과정 중학교 역사①·②와 고등학교 한국사1·2, 세계사, 동아시아 역사 기행, 역사로 탐구하는 현대 세계의 차시별 수업 자료입니다. 빌드 과정 없이 HTML 파일만으로 작동하는 정적 사이트입니다.

주소: https://simtaesoo.github.io/history/

차시마다 **수업 슬라이드**와 **시뮬레이션**, 단원마다 **학습지**와 **게임**이 있습니다.

## 폴더 구조

```
index.html                  첫 화면 (학교급·과목)
<과목>/index.html            과목 목록 (단원 → 차시 → 자료, 성취기준 함께 표시)
<과목>/<단원>/slidesN.html   N차시 수업 슬라이드
<과목>/<단원>/sim.html#N     N차시 시뮬레이션
<과목>/<단원>/worksheet.html 단원 학습지 (차시마다 한 면, #N으로 바로 이동)
<과목>/<단원>/app-*.html     단원 게임
assets/
  catalog.js                전체 목차, 사이트 이름·제작자, 만들어진 자료(FILES)
  standards.js              성취기준 문장
  deck.css, deck.js         수업 슬라이드 엔진
  worksheet.css, worksheet.js  학습지 양식
  site.css, site.js         목록 페이지
  photo/                    사진 파일과 출처·이용 조건(CREDITS.md)
tools/check.py              자동 검사 (JS 오류, 깨진 링크, 화면 넘침)
```

## 수업 슬라이드 사용법

- **→ / 스페이스 / 화면 클릭**: 질문이 하나씩 나타나고, 다 나오면 다음 장으로 넘어갑니다.
- **← / 화면 왼쪽 클릭**: 되돌리기
- **N**: 교사 메모(질문 의도, 예상 답, 후속 질문) · **F**: 전체 화면
- 주소 끝에 `#5`를 붙이면 5장부터 열립니다.

슬라이드 화면에는 사진과 낱말, 질문만 둡니다. 설명은 교사 메모에 있습니다. 수업 전체를 꿰는 질문 하나로 시작해 마지막 장에서 한 문장 쓰기로 돌아옵니다.

## 학습지 사용법

- **[정답 보기]**를 누르면 빈칸과 예시 답이 붉은 글씨로 나타납니다. 켠 채 인쇄하면 교사용 정답지가 됩니다.
- **[인쇄하기]**는 A4 기준입니다. 인쇄 설정에서 '배경 그래픽'을 켜 주세요.

## 자주 바꾸는 곳

- **사이트 이름과 제작자**: `assets/catalog.js` 맨 위의 `name`, `author`
- **새 자료 등록**: 파일을 넣고 `assets/catalog.js` 아래 `FILES`에 적으면 목록 페이지의 회색 표시가 링크로 바뀝니다.
- **사진**: `assets/photo/`에 넣고 `CREDITS.md`에 출처·이용 조건을 적습니다. 잔혹한 사진은 쓰지 않습니다.
