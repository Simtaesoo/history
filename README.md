# 역사 수업 실험실

2022 개정 교육과정 중학교 역사·고등학교 한국사 수업용 시뮬레이션·게임 자료입니다. 빌드 없이 HTML만으로 작동합니다.

- `index.html` 메인 화면
- `hangeul/sim.html` 훈민정음 창제 원리 실험실 (발음 기관 상형 · 가획 · 천지인 · 글자 조합 게임 · 서문 사료)
- `korea1/` 역사② Ⅰ. 국가의 형성과 발전 (중2, 9차시)
  - `index.html` 단원 첫 화면 — 차시 목록과 차시별 시기 막대
  - `slides1~9.html` **차시별 수업 슬라이드** — 목표 → 영상 → 개념·사료 → 게임(타이머) → 확인 문제 → 생각 질문 → 정리 빈칸 → 나가기 전 한 문제. ←/→ 넘기기 · O 전체 보기 · N 교사 메모 · F 전체 화면
  - `lesson.html?n=1~9` 차시 자료 — 학습 목표, 추천 영상, 교사 발문(체크), 생각 질문 3개, 게임, 활동지 인쇄, **수업 모드**(TV용 한 장씩 보기 · 타이머 · ←/→)
  - `game.html?g=l1…l9` 차시별 수업 게임 — 분류·재판·단서 맞히기·빈칸·국력 그래프·연표, 모둠 점수판과 타이머
  - `sim.html` 한강 쟁탈전 371–562 시뮬레이션 — 11개 결정 장면, 모둠 투표, 실제 역사 공개, 지도 변화
  - 내용 고치기: `data.js`(차시 자료) · `games.js`(게임) · `sim-data.js`(시뮬레이션) · `_build_decks.py`(슬라이드 원고 → `python3 _build_decks.py`로 다시 만들기)
